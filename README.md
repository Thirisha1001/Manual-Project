
# SkillSwap – Manual Testing Project

## Project Overview
SkillSwap is a web-based application that allows users to connect with others and exchange skills through learning sessions. Users can explore skill partners, send requests, schedule sessions, and communicate through chat.

## Project Objective
The objective of this project is to test the functionality, usability, and reliability of the SkillSwap web application through manual testing.
